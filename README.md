# dsh-voice-input

**状态：规划中 · Status: planned.** 尚无可用版本。

## 要解决什么

用 dsh 写代码或长提示词时，**键盘输入是瓶颈**；手机上更是如此。而现有 `voice` 类插件多为**朗读/播报（TTS）**方向，输入侧几乎空白。

## 计划做什么

在输入框上提供一个**按住说话 → 转文字 → 填入输入框**的入口：

- 录音在浏览器内完成，**由用户自己配置 STT 服务**（本地模型或自有 API Key）
- 转写结果**先填入输入框供修改**，不直接发送
- 可选：识别中英混说、自动加标点

## 不做什么

- **不**自带语音服务、**不**代管任何 API Key
- **不**做 TTS（朗读回答）——那是另一类插件
- 不上传音频到本项目作者的任何服务器（本项目没有服务器）

## 隐私立场

语音是最敏感的数据之一。默认**只在本地处理**；如果用户选择接入云端 STT，请求由**用户自己的凭据**直达用户选择的服务商，本插件只做 UI 与串联。
